## What this is

A checked collection of Windows tweaks. Every entry names the subsystem it changes,
states what that costs, and gives an exact way to undo it. A companion list covers
the popular tweaks that did not survive the same checks.

It started as a text file of notes and a few batch scripts assembled from forum
posts. Read properly, most of what was in them was wrong: values the kernel
silently ignores, commands removed from Windows years earlier, and a block that
enabled the latency features its own comment claimed to disable. Everything here
was rebuilt from that, with the reasoning written down.

## How to work through it

<Steps>

1. **Measure first.** Ten minutes of LatencyMon and one frame-time capture before
   changing anything. Without a baseline there is no way to tell a fix from a
   placebo.

2. **Read the page for whatever you are about to change**, so the mechanism and the
   cost are clear before the value is written.

3. **Apply one category, then reboot.** By hand, or with the script. If something
   feels off the next day, there is only one category to revert.

4. **Measure again.** Keep whatever moved the number, revert whatever did not.

</Steps>

:::caution[Before applying any of this]
These settings change how Windows schedules work, manages power and handles the
network. Some are trades rather than upgrades, and what helps on one machine does
nothing on another. Apply one category at a time, reboot in between, and read the
[debunked list](reference/debunked/) before going looking for more tweaks elsewhere.
:::
