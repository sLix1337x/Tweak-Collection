## What the verdicts mean

| Verdict | Meaning |
| --- | --- |
| <span class="tc-verdict tc-verdict-invalid">Invalid</span> | Writes a value the system does not accept, or calls something that no longer exists. Does nothing, silently. |
| <span class="tc-verdict tc-verdict-placebo">Placebo</span> | A real setting with no measurable effect. |
| <span class="tc-verdict tc-verdict-harmful">Harmful</span> | Measurably makes something worse. |
| <span class="tc-verdict tc-verdict-situational">Situational</span> | Can help on specific hardware, but not as a blanket recommendation. |
| <span class="tc-verdict tc-verdict-situational">Unproven</span> | Real, read by the system, and it does change behaviour. What is missing is evidence that any particular value is an improvement. |
| <span class="tc-verdict tc-verdict-invalid">Superseded</span> | Not wrong, but a documented setting does the same job and reverts cleanly. |

## Why the list is this long

Almost every entry is one of three cases.

**Correct advice for an older Windows.** The setting was real on Windows 7 or 10 and
was never re-checked against a current build. TCP Chimney Offload and `IoPageLockLimit`
are the clearest: both genuine, both gone.

**A real setting with an unproven benefit.** The value exists, the system reads it, and
it changes behaviour, but no measurement shows the change is an improvement.
`Win32PrioritySeparation` is the canonical example. Marked **Unproven** rather than
Placebo, because "nothing measurable has been shown" and "nothing happens" are
different claims.

**A value copied wrong, then copied from the copy.** `TcpAckFrequency = 0` is outside
the key's valid range. `*EEE = 1` enables the feature the comment above it claims to
disable.

All three survive because Windows does not complain: `Set-ItemProperty` writes any name
it is given, the value appears in `regedit`, and nothing reads it. Checking a value
against [the binary that would read it](../../guides/reading-the-binary/) rules out an
entire category. For the other two: know the mechanism, check the Windows version,
measure the result — see [how a tweak earns its place](../../start/method/).
